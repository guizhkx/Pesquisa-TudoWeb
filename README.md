# Pesquisa-TudoWeb
Pesquisa de satisfação desenvolvida em Python

Projeto desenvolvido em Python para realizar uma pesquisa de satisfação com 50 entrevistados.

O programa solicita nome, idade e avaliação do atendimento, utilizando estruturas de repetição e decisão.

**Opções de avaliação:**

* 1 — Excelente
* 2 — Bom
* 3 — Ruim

Foram realizados testes com 10 entrevistados para validar o funcionamento do programa.

**Tecnologia utilizada:** Python 3.
